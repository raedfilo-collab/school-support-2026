طريقة تفعيل التعديل من الإنترنت:

1. أنشئ مستودعاً خاصاً (Private repository) على GitHub وارفع الملفات الثلاثة: index.html و content.json و classroom-illustration.png بالإضافة إلى .pages.yml (ملف مخفي).
2. في Netlify، اربط الموقع الموجود بمستودع GitHub من إعدادات Build & deploy / Continuous deployment، أو أنشئ موقعاً جديداً باستيراد المستودع. تأكد أن مجلد النشر هو جذر المستودع.
3. افتح https://pagescms.org/ وسجل الدخول بحساب GitHub وثبّت تطبيق Pages CMS للمستودع.
4. اختر المستودع ثم محتوى الموقع؛ عدّل الحقول واضغط Save/Publish. سيحفظ Pages CMS التغييرات في content.json على GitHub، وسيعيد Netlify نشر الموقع تلقائياً بعد الربط.
5. لا تضع مفاتيح الدخول أو البيانات الشخصية للمتبرعين في المستودع. أدخل الأرقام فقط بعد مطابقتها مع كشف حساب الجمعية.

مهم: رفع ZIP مباشرة إلى Netlify Drop لا يوفر مزامنة التعديلات. يجب ربط GitHub بـ Netlify أولاً.
مهم: إذا لم يظهر ملف .pages.yml عند الرفع، فعّل عرض الملفات المخفية.
